CATT setup for Windows
======================

WHAT TO DO
----------

1. Unzip this whole folder somewhere you can find again.
   Documents is fine. Do not run it from inside the zip file.

2. Double-click:  Install CATT.bat

3. If Windows shows a blue "Windows protected your PC" box,
   click "More info" and then "Run anyway". This appears for any
   downloaded script that Microsoft has not seen before. You can
   open the .bat file in Notepad first if you want to read it.

4. Wait. The package install takes a few minutes.

5. Your browser opens with the CATT command builder.

After the first time, use "Start CATT.bat" instead.


WHAT IT INSTALLS
----------------

A folder called CATT next to this file, containing the project
from https://github.com/mgbpm/CATT and a private Python
environment inside it (the .venv folder).

Nothing is installed system-wide. Nothing is added to your PATH.
To uninstall, delete the CATT folder.

You need Python 3.9 or newer installed first. If you don't have
it, the script tells you and points you at python.org. When you
run that installer, tick "Add python.exe to PATH" on the first
screen.


A NOTE ON DEPENDENCIES
----------------------

This setup deliberately ignores CATT's own requirements.txt.

That file is a full `pip freeze` from a 2023 machine. It pins
numpy 1.24 and torch 2.0, neither of which publishes builds for
Python 3.12 or newer, so pip tries to compile them from source
and the install fails. CATT never imports torch at all.

requirements-catt.txt lists only what CATT actually imports.
That is why this works where the documented instructions don't.


USING IT
--------

The builder page shows every CATT option with a plain-English
explanation. Tick what you want and press Run; the log streams
into the page. The black console window must stay open the whole
time - it is the program.

Before anything else, run the "Download all source data" recipe.
CATT ships with no data; it fetches from ClinVar, ClinGen and
GenCC on first use. This pulls several gigabytes and takes a
while.

Files you create land in the CATT folder. There is an "Open the
CATT folder" button under the log once a run finishes.


IF SOMETHING GOES WRONG
-----------------------

"Python was not found" or the Microsoft Store opens
    Windows is intercepting the python command. Install Python
    from python.org, ticking "Add python.exe to PATH".

The download fails
    A corporate proxy or firewall is blocking github.com or
    pypi.org. This needs your IT team.

The page says it lost contact with the runner
    The black console window was closed. Start it again.

A run stops with a 403 or connection error
    That source's server refused the download. ClinGen's
    endpoints do this occasionally; try again later.
