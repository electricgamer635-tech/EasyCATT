--sources

Sources

Click in join order. An amber dot means that source hasn't been downloaded yet.

what this does

This picks which datasets to pull from. Using all of them is slow. If you also ask for a joined CSV, the sources are stitched together with left joins following your order, matching on shared values like gene symbol, so the first source you click decides which rows survive.

--gene · --variant · --columns

Filters

what this does

This keeps only the genes you name in the data, comma-separated. Pair it with --expand or you will miss rows where your gene shares a cell with others.

what this does

This keeps only rows for the Variation IDs you name — ClinVar's own numeric ID for a variant, such as 8602 or 5760. Comma-separate for more than 1.

what this does

This limits the output to the columns you name, comma-separated. Leave it empty to keep all.

encoding

Shape of the output

All of these add new columns rather than replacing the originals, so you can turn on a buch at once.

--joined-output · --template-output · --na-value

Files produced

what this does

This merges your chosen sources into one CSV instead of writing a separate file per source.

what this does

Gathers every generated English sentence into one text file which is the thing you would actually paste into a language model. Needs --template on, since otherwise no sentences exist to collect.

what this does

This replaces missing values everywhere with whatever you type. Useful because plenty of models and spreadsheet tools choke on empty cells.

--loglevel · --force · --counts

Housekeeping

what this does

How chatty the run is with you. Without it CATT works in silence and you will sit there in confusion wondering whether it froze or if it's just slow. Info is a good default, debug is for when something has clearly gone wrong.

what this does

Single run does one pass over your filters. Batch mode loops over a list of Variation IDs, writing one file each, using the fixed source list the project's batch scripts use. Nothing else on this page applies in batch mode.

batch

Variant list

One Variation ID per line. Each one gets its own output file.

Created inside the CATT folder if it doesn't exist. This runs main.py once per variant, so a long list takes a long time.
